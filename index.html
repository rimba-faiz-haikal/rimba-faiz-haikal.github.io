Himbauan

Web ini akan kosong saat pertama kali dibuka. Anda perlu menambahkan kosakata secara manual. Gunakan web ini untuk mencatat kata yang sedang dipelajari dan dihafal.

Tujuan dari web ini adalah sebagai kamus pribadi yang sederhana, praktis, dan fokus pada kebutuhan belajar Anda. Anda dapat menyimpan kosakata, mengelompokkan berdasarkan kumpulan, serta mengulang kembali materi kapan saja.

Cara Penggunaan

  • Klik tombol (+) untuk menambahkan kosakata
  • Isi kanji, furigana, romaji, dan arti
  • Pilih kategori kumpulan sesuai kebutuhan
  • Gunakan pencarian untuk menemukan kata dengan cepat
  • Gunakan filter untuk melihat berdasarkan kumpulan
  • Tandai kata penting menggunakan fitur favorit
  • Gunakan mode flashcard untuk latihan menghafal
  • Hapus kata yang tidak diperlukan
